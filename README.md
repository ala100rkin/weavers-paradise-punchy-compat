# Weavers Paradise Punchy Compatibility

Standalone NeoForge client-side compatibility add-on for Minecraft 1.21.1. It renders Weavers Paradise cosplay armor correctly with Punchy!.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.199 or compatible 21.1.x build
- [Weavers Paradise](https://modrinth.com/mod/weavers-paradise) 1.6.3+
- [Punchy!](https://modrinth.com/mod/punchy-fpa)

## Build

Run `gradlew.bat build`. The mod JAR is written to `build/libs`.

This add-on is independent of the other Weavers Paradise compatibility add-ons.
